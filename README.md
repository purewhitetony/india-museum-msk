# Музей Индии · рабочая площадка

Сайт-презентация и виртуальная экскурсия по будущему Музею Индии в Москве (пер. Лихов, 12/2).
Репозиторий публикуется через GitHub Pages, чтобы команда видела ход работы.

## Режимы

| Путь | Что это |
|---|---|
| `/` | Лендинг для меценатов: миссия, залы, три формата музея, как поддержать, анкета |
| `/rabota/` | Хаб рабочей группы: режимы просмотра, журнал работы, следующие шаги |
| `/razmetka/` | Планы трёх уровней, зоны, точки 360°, маршрут, фотореференсы комнат |
| `/sayt/` | Черновик сайта для инвесторов |

В финале здесь останется только сайт.

## Откуда берётся содержимое

Рабочие файлы (исходники картинок, фото из объявлений, скрипты, 3D) живут в рабочей папке проекта
и в репозиторий не попадают. Сюда выгружается только чистовое:

- `assets/plans/` — планы помещения
- `assets/referensy/` — коллажи-референсы зон (JPG)
- `assets/img/` — изображения сайта
- `data/zones.json`, `data/zones.js` — разметка: зоны, точки 360°, маршрут
- `razmetka/index.html` — собирается скриптом из разметки

`index.html` (хаб) и `sayt/index.html` правятся здесь вручную.
